💡 SkyBridge Installer

Bluetooth-Mesh-Lampen (z. B. OPPLE BLE2) per ESP32 in Home Assistant – Firmware direkt aus dem Browser installieren.

1. Board anstecken & installieren

Board per USB anschließen und auf den Knopf klicken. Der Chip wird automatisch erkannt und die passende Firmware installiert.

Dein Browser unterstützt das leider nicht. Bitte Chrome oder Edge am PC/Mac verwenden (nicht am Handy). Die Seite muss über HTTPS geöffnet werden.

Beim ersten Mal „Gerät löschen“ (Erase) bestätigen.

Verbindung klappt nicht?
  • Alle Programme schließen, die den Anschluss belegen könnten (Arduino IDE, VS Code/PlatformIO, 3D-Drucker-Software, andere Browser-Tabs).
  • BOOT-Taste gedrückt halten, kurz RESET drücken, BOOT loslassen – dann nochmal versuchen.
  • Windows: Boards mit CH340/CP210x-Chip brauchen evtl. einen Treiber.
  • Arduino Nano ESP32: Taste B1 gedrückt halten und dabei RESET drücken.

2. Einrichten

  1. Mit dem WLAN SkyBridge-Setup verbinden (Passwort skybridge).
  2. http://192.168.4.1 öffnen, Board, WLAN und MQTT eintragen, speichern.
  3. Die Bridge startet neu. Ihre IP im Router nachsehen und im Browser öffnen.
  4. Unter „Lampen“ die Export-Datei der Telink-SIG-Mesh-App hochladen, speichern.
  5. Die Lampen erscheinen automatisch in Home Assistant (MQTT).

Ausführliche Anleitung im README des Projekts.
